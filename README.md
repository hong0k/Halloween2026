# HONGOK FILM

PC와 모바일에서 사용하는 네컷 사진 웹앱입니다. 정적 HTML/CSS/JavaScript로 동작하며 사용자 사진을 서버로 전송하지 않습니다.

## 로컬 실행

```sh
cd /workspace/Halloween2026
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저에서 localhost:8000으로 접속합니다. 카메라는 localhost 또는 HTTPS에서만 사용할 수 있습니다. 휴대폰에서는 HTTPS로 배포된 사이트를 사용하세요. 파일을 직접 여는 대신 HTTP 서버를 사용해야 프레임 설정을 읽을 수 있습니다.

## 기능

- 기본 / 할로윈 프레임과 같이 찍기 / 혼자 찍기 독립 선택, 캐릭터 5명 선택
- 여러 사진 업로드, 선택한 칸 교체, 사진별 드래그·키보드 방향키·확대·좌우 반전
- 카메라 촬영, 3/5초 타이머, 전후면 전환, 거울 모드
- 문구 입력, 1200×1560 JPG/PNG 선택 저장, 지원되는 모바일 브라우저의 이미지 공유
- 모바일 카메라 권한 거부 시 업로드로 이용 가능. HEIC 등 브라우저가 해독하지 못하는 사진은 JPG/PNG로 변환 필요

사진과 편집 상태는 메모리에만 유지됩니다. 새로고침하면 사라집니다. 현재 캐릭터 실루엣과 프레임은 임시 디자인입니다.

## 프레임 교체

`assets/frames.json`에서 이미지 경로를 지정합니다. 모든 경로는 사이트 루트 기준의 **상대 경로**를 사용합니다(예: `assets/kim-1.png`). 외부 이미지 URL보다 저장소에 포함한 PNG를 권장합니다.

- `characters[].poses`: 각 칸에 겹칠 투명 PNG 4장. 각 이미지 크기 **520×610**. 캐릭터가 오른쪽에 오고 사용자 영역이 투명하게 보이도록 만드세요. PNG는 칸 전체에 맞춰 그려집니다. `null`이면 임시 실루엣을 표시합니다.
- `overlays.together`(기본 프레임), `overlays.halloween`(할로윈 프레임): 전체 프레임 투명 PNG, **1200×1560**. 사진 영역을 투명하게 비워 주세요. `null`이면 기본 프레임을 사용합니다.
- 사진 영역의 좌상단 좌표: (60,160), (620,160), (60,800), (620,800). 각각 520×610.
- 전체 프레임 위에 하단 문구와 날짜가 표시됩니다. 문구 기준선 y=1470, 날짜 y=1515이므로 해당 공간을 비워주세요.

카메라의 캐릭터 영역 안내는 임시 가이드이며 실제 포즈 이미지는 최종 합성에 적용됩니다.

## GitHub Pages 배포

1. 저장소 기본 브랜치 `main`에 파일을 커밋·푸시합니다.
2. GitHub 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
3. 포함된 `Deploy GitHub Pages` 워크플로가 정적 파일을 배포합니다. 이후 `main` 푸시마다 자동 배포됩니다.
4. 기본 URL: `https://hong0k.github.io/Halloween2026/`

코드에 인증키가 필요하지 않습니다. 별도 빌드나 npm 의존성도 없습니다. 배포 계정 권한과 저장소 요금제에 따라 Pages 사용 가능 여부를 확인하세요.

할로윈 배경은 `backgrounds.halloween`에서 화면 테마별로 연결합니다. `pumpkin`은 `assets/background-02.png`, `lime`은 `assets/background-01.png`, `pink`는 `assets/background-03.png`입니다. 이미지는 사진 아래에 배치됩니다. 라임 배경의 해골은 앱에서 좌우 여백에 맞춰 합성합니다. 펌킨 배경의 유령과 박쥐는 왼쪽 상단에 배치되어 별도 위치 보정이 없습니다.

빈티지 핑크의 `background-03.png`는 사용자가 제공한 `background-03-original.png`의 복사본입니다. 원본 제목과 그라데이션을 재생성하지 않습니다. `decoration_sources.pink`에서 기존의 밝은 모서리 장식만 분리해 사진 아래에 합성하고, 은은한 무늬는 별도 캔버스 레이어로 그립니다. 제목 영역에는 장식을 그리지 않습니다.

## 내 캐릭터 업로드

같이 찍기 → 「＋ 내 캐릭터」에서 이미지를 불러옵니다. 한 장은 네 칸에 같은 포즈로 적용하고, 여러 장은 1번째 칸부터 최대 4장까지 배치합니다. 「선택한 칸 포즈 바꾸기」는 해당 칸만 교체합니다.

편집 대상을 「내 사진 / 내 캐릭터」로 선택하면 각 이미지를 따로 드래그·방향키·확대·반전·초기화·삭제할 수 있습니다. 캐릭터 확대는 30~300%이며, 최초에는 사진 오른쪽에 전체 이미지가 들어오도록 배치합니다. 카메라 미리보기에도 선택한 칸의 캐릭터가 겹쳐 표시되고 결과에는 한 번만 합성됩니다. 「선택한 포즈·위치를 네 칸에 적용」으로 네 칸을 통일할 수 있습니다.

배경 제거 기능은 제공하지 않습니다. 투명 PNG/WebP의 투명도는 보존하고, 일반 JPG/PNG는 배경을 포함해 합성합니다. 업로드 파일은 기기 브라우저 메모리에서만 처리되며 새로고침하거나 전체 초기화하면 사라집니다.

## 기본 프레임 스타일

기본 프레임을 선택하면 화이트·블랙·모노크롬 스타일을 고를 수 있습니다. 화이트와 블랙은 사진 원래 색을 유지하고, 모노크롬은 사진·캐릭터를 합성할 때만 흑백 필터를 적용합니다. 원본 파일과 편집 상태는 보존되어 다른 스타일로 돌아가면 컬러가 복원됩니다. 카메라 미리보기와 JPG/PNG 저장에도 반영됩니다.

세 스타일 모두 1200×1560px, 사진 영역 520×610px 및 기존 좌표를 유지합니다. 단색 배경, HONGOK FILM 타이포그래피, 컷 번호와 인화지 선을 Canvas로 그리므로 이미지 생성이나 외부 브랜드 로고 없이 선명하게 출력됩니다. 화면 테마와 기본 프레임 스타일은 별도로 선택합니다.
