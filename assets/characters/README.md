각 캐릭터 안의 `basic/`은 기본·싸이월드 공용, `halloween/`은 할로윈용입니다.

- 기본용: 투명 PNG를 `01.png`, `02.png`처럼 포즈 순서대로 업로드하세요.
- 할로윈용: 배경이 있는 JPG를 `01.jpg`~`04.jpg`로 업로드할 수 있습니다. 투명 PNG도 사용할 수 있습니다.
- 원본 이미지 비율은 유지하세요. 크기와 배치는 사이트에서 조정합니다.
- `.gitkeep`은 빈 폴더를 GitHub에 표시하기 위한 파일입니다. 이미지가 아니며 그대로 두어도 됩니다.
- 이미지를 업로드한 뒤 연결을 요청해주세요. 빈 폴더를 만드는 것만으로 사이트에 자동 적용되지는 않습니다.
